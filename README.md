# Jazz Conecta — Hub

Página de entrada do Jazz Conecta, publicada pelo GitHub Pages:

- **Hub** (`index.html`): todos os módulos do sistema, por papel, com links para o sistema em produção.
- **Imóveis com telefone na tela** (`oportunidades/`): busca pública de imóveis de proprietário (OLX e VivaReal).

O código do sistema (telas, banco, rotinas) fica em `imobjazz-eng/jazz-lead-conecta`.
A página `oportunidades/` é cópia de `lp-oportunidades/` daquele repositório: corrija lá e copie para cá.
O feed XML dos portais é outro projeto (`imobjazz-eng/jazz-xml`).

Para mudar o endereço do sistema, altere a constante `SISTEMA` em `index.html`.
